# Forms 1.2.5

Administrator UI refinement release.

## Changed

- forms-list title aligned with **Elenco moduli**;
- isolated Back button removed from form submissions and replaced by a single **← Elenco moduli** action in the header;
- graphical icons added to **Esporta**, CSV, Excel and PDF;
- summary cards on form submissions and Recent submissions are clickable instant status filters with an active state;
- **Totale** resets the status filter immediately;
- the live status badge in **Gestisci invio** is larger and moved beside the panel title;
- changing the status selector updates the large badge immediately.

## Compatibility

- includes the 1.2.4 submission-detail hotfix;
- Joomla 6.0+;
- PHP 8.3+;
- no database schema changes;
- existing forms, status colors and submissions are preserved.
