# Forms 1.2.2

Usability and submissions-management release for the Joomla administrator UI.

## Added

- redesigned **Invii recenti** page with summary cards, form/status filters, search and rows selector;
- selectable submission rows with **Seleziona tutti / Deseleziona tutti**;
- single **Esporta** menu for CSV, Excel and PDF, exporting only the selected submissions;
- redesigned single-submission view with data on the left and **Gestisci invio** on the right;
- clickable email template cards with a modal facsimile preview using sample values only for fields present in the current form;
- administrator/user preview tabs and **Usa questo template** action.

## Changed

- simpler Italian administrator terminology: **Riepilogo**, **Importa dati**, **Guida**, **Nuovo modulo**, **Modifica modulo**, **Vedi invii**, **Elenco moduli**;
- per-form table setting is named **Colonne della tabella**;
- submission management uses **Salva e chiudi**, returning to the form's submissions list;
- existing per-form custom statuses and configurable data columns remain supported.

## Compatibility

- Joomla 6.0+
- PHP 8.3+
- no destructive database changes;
- existing forms and submissions are preserved.
