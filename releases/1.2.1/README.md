# Forms 1.2.1

Maintenance and usability release for the Joomla administrator UI.

## Added

- clickable email template cards with a modal facsimile preview for Standard, Minimal, Institutional, Card and Compact layouts;
- back button from a single submission to that form's submissions list.

## Changed

- primary actions use Joomla/Bootstrap administrator button styling so colors adapt correctly to the active administrator theme, including dark mode;
- email template preview reflects the configured Forms brand name and accent color.

## Compatibility

- Joomla 6.0+
- PHP 8.3+
- no database schema changes from Forms 1.2.0;
- existing forms and submissions are preserved.
